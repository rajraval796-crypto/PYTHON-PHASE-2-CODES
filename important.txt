map:
The map() function applies a given function to all items in an input list 
(or any iterable) and returns a map object (an iterator).
map(function, iterable)
example:doubled = list(map(lambda x: x * 2, numbers))

filter:
The filter() function constructs an iterator from elements of an iterable for which a given
function returns True.
filter(function, iterable)

reduce:
The reduce() function performs a rolling computation to sequential pairs of values in a list. 
It is part of Python's built-in functools module, so you must import it first.
from functools import reduce

reduce(function, iterable)
